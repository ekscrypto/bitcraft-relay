Region maps

Vector maps of the nine player-buildable BitCraft regions — 7, 8, 9, 12, 13, 14, 17, 18, 19 — biome-colored with labels and the superhex grid, generated 2026-11-10 from the relay's roads terrain cache (region.map.pb snapshots). Each region ships as an SVG (primary) and a claims overlay JSON (claim name, centroid cx/cz, small-hex n/e coordinates, tile count).
